## Prioridad Baja

- negocios / produccion pasiva en mobile
- ranking competitivo mas profundo

## Regla Operativa

- no romper la economia cerrada en Fase 2
- no tocar admin movil sin objetivo muy claro
- preferir expansiones compactas sobre modulos profundos
- toda nueva feature debe pasar por QA manual y validacion tecnica minima
