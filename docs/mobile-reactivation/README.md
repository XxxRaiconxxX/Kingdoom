# Reactivacion Mobile - Kingdoom

Esta carpeta documenta la reactivacion de la app movil en `apps/mobile`.

Estado actual:
- **Fase 1:** cerrada
- **Fase 2:** cerrada
- **Fase 3:** cerrada

Resultado del plan:
- `apps/mobile` queda consolidada como frente movil oficial;
- la web en `src/` sigue siendo la fuente de verdad funcional;
- la app mobile ya cuenta con base jugable y economica estable para evolucionar fuera del plan de reactivacion.

Documentos:
- `mobile-v1-parity-matrix.md`: matriz `web vs mobile` por dominio y estado actual.
- `mobile-contract-alignment.md`: contratos y tipos alineados durante la reactivacion.
- `mobile-reactivation-backlog.md`: backlog historico de las Fases 1-3 ya ejecutadas.
- `mobile-qa-manual-checklist.md`: checklist operativa para validar la app mobile en QA manual.
- `mobile-post-reactivation-backlog.md`: backlog nuevo para la etapa posterior a la reactivacion.
- `antigravity-1-mobile-sprint.md`: brief historico del sprint de superficie/UX.
- `antigravity-2-mobile-sprint.md`: brief historico del sprint funcional/economico.

Decisiones congeladas que siguen vigentes:
- El target oficial es `apps/mobile`.
- La carpeta raiz `android/` se trata como artefacto derivado, no como producto movil principal.
- Admin movil sigue fuera del alcance normal salvo pedido explicito.
- `Archivist` y `Anime` se mantienen como modulos compactos.

Siguiente etapa recomendada:
- no abrir otra "fase de reactivacion";
- trabajar desde `mobile-post-reactivation-backlog.md` con prioridades concretas de producto, QA y expansion.
