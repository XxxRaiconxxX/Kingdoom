# Reactivacion Mobile - Kingdoom

Esta carpeta consolida la **Fase 1** de reactivacion de la app movil en `apps/mobile`.

Objetivo:
- tratar `apps/mobile` como unico frente movil real;
- usar la web como fuente de verdad funcional;
- dejar una base de ejecucion clara para Jarvis, Antigravity 1 y Antigravity 2.

Documentos:
- `mobile-v1-parity-matrix.md`: matriz `web vs mobile` por dominio y estado.
- `mobile-contract-alignment.md`: contratos y tipos que deben unificarse o alinearse.
- `mobile-reactivation-backlog.md`: backlog priorizado y asignado.
- `antigravity-1-mobile-sprint.md`: prompt/brief operativo para superficie y UX.
- `antigravity-2-mobile-sprint.md`: prompt/brief operativo para integracion y features complejas.

Decisiones ya congeladas:
- El target oficial a retomar es `apps/mobile`.
- La carpeta raiz `android/` no se toma como producto movil principal.
- La meta inmediata no es paridad total, sino **paridad operativa minima**.
- Admin movil queda fuera del primer corte.
